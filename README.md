# Sistema Bancário em Java

Projeto desenvolvido para praticar Programação Orientada a Objetos em Java.

## Funcionalidades
- Criar conta
- Depositar dinheiro
- Sacar dinheiro
- Consultar saldo

## Tecnologias
- Java
- Scanner
- ArrayList

## Objetivo
Praticar lógica de programação e conceitos de orientação a objetos.
